01

Creación de Jobs · Reporte Diario

📋 Enunciado

La Oficina de Grados y Títulos requiere generar automáticamente todos los días a las 08:00 AM un reporte con la cantidad de trámites registrados durante el día anterior.


  • Crear un Job.
  • Crear un Step en T‑SQL.
  • Programar el Job diariamente.
  • Registrar el resultado en una tabla de auditoría.

💻 Script Principal

                    CREATE TABLE AuditoriaJobs(
                        Id INT IDENTITY PRIMARY KEY,
                        Fecha DATETIME,
                        TotalTramites INT,
                        Mensaje VARCHAR(200)
                    );
                    GO

                    INSERT INTO AuditoriaJobs
                    SELECT
                        GETDATE(),
                        COUNT(*),
                        'Reporte generado correctamente'
                    FROM Tramites
                    WHERE CAST(FechaRegistro AS DATE) = CAST(GETDATE()-1 AS DATE);
                    GO

⚙ Creación del Job

                    EXEC sp_add_job
                        @job_name = 'Reporte Diario Tramites';

                    EXEC sp_add_jobstep
                        @job_name = 'Reporte Diario Tramites',
                        @step_name = 'Generar Reporte',
                        @subsystem = 'TSQL',
                        @command = 'EXEC GenerarReporte';

🚀 Flujo del Proceso

08:00 AM Ejecuta SQL Agent Consulta Trámites Guarda Auditoría Finaliza

✅ Buenas Prácticas

  • Uso de tablas de auditoría.
  • Automatización mediante SQL Server Agent.
  • Separación de lógica con procedimientos.
  • Registro de fecha y hora de ejecución.
  • Nombres descriptivos y mantenibilidad.

✔ El Job se ejecuta diariamente a las 08:00 AM y registra el resultado en AuditoriaJobs.

Actualización Automática de FechaUltMod

📋 Enunciado

Automatizar la actualización semanal del campo FechaUltMod para todos los trámites que permanezcan en estado EN_PROCESO, registrando la ejecución en el historial del Job.

💻 Script UPDATE

                    UPDATE Tramites
                    SET FechaUltMod = GETDATE()

                        @subsystem = 'TSQL',

03

Limpieza Automática de Registros Temporales

📋 Enunciado

Crear un Job que se ejecute mensualmente para mover los registros antiguos (más de 180 días) a una tabla histórica y luego eliminarlos de Tramite.LogTemporal, garantizando integridad mediante transacciones.

💻 Script T‑SQL

                    BEGIN TRY
                        BEGIN TRANSACTION

                        INSERT INTO LogTemporalHistorico
                        SELECT *
                        FROM Tramite.LogTemporal
                        WHERE FechaRegistro <= DATEADD(DAY, -180, GETDATE());

                        DELETE
                        FROM Tramite.LogTemporal
                        WHERE FechaRegistro <= DATEADD(DAY, -180, GETDATE());

                        COMMIT;
                    END TRY
                    BEGIN CATCH
                        ROLLBACK;
                        PRINT 'Error durante la ejecución';
                    END CATCH;

⚙ SQL Server Agent

                    EXEC sp_add_job
                        @job_name = 'Limpieza Mensual LogTemporal';

                    EXEC sp_add_jobstep
                        @job_name = 'Limpieza Mensual LogTemporal',
                        @step_name = 'Mover y Eliminar Registros',
                        @subsystem = 'TSQL',
                        @command = 'EXEC dbo.LimpiezaLogTemporal';

  • Uso de BEGIN TRANSACTION para consistencia.
  • Implementación de TRY…CATCH.

SQL Server Alert Center

📋 Enunciado

Crear un Alert que notifique cuando la base de datos genere errores de severidad ≥ 17 durante el registro de trámites. Incluye creación del operador, Alert y prueba.

💻 Script T‑SQL

                    EXEC msdb.dbo.sp_add_operator
                        @name = 'DBA_ADMIN',
                        @email_address = 'dba@empresa.com';
                    GO

                    EXEC msdb.dbo.sp_add_alert
                        @name = 'ErrorCritico17',
                        @severity = 17;
                    GO

                    EXEC msdb.dbo.sp_add_notification
                        @alert_name = 'ErrorCritico17',
                        @operator_name = 'DBA_ADMIN',
                        @notification_method = 1;

05

Automatización con Database Mail

📋 Enunciado

Crear un Job que diariamente identifique los trámites pendientes por más de 30 días, genere un reporte y lo envíe por correo utilizando Database Mail.

💻 Script T‑SQL

                    CREATE PROCEDURE sp_ReportePendientes
                    AS
                    BEGIN
                        BEGIN TRY
                            INSERT INTO AuditoriaReportes
                            SELECT GETDATE(), COUNT(*)
                            FROM Tramites
                            WHERE DATEDIFF(DAY, FechaRegistro, GETDATE()) > 30;

                            EXEC msdb.dbo.sp_send_dbmail
                                @profile_name = 'PerfilMail',
                                @recipients = 'admin@empresa.com',
                                @subject = 'Reporte Diario',
                                @body = 'Reporte generado correctamente';
                        END TRY
                        BEGIN CATCH
                            PRINT ERROR_MESSAGE();
                        END CATCH
                    END;

✅ Buenas Prácticas

  • Uso de procedimientos almacenados.
  • TRY…CATCH para manejo de errores.
  • Auditoría de ejecuciones.
  • Automatización con SQL Server Agent.
  • Uso de Database Mail para notificaciones.
